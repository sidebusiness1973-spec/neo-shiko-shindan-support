# Neo思考診断｜サポート・お問い合わせ

「Neo思考診断」をご利用いただきありがとうございます。

Neo思考診断は、いくつかの質問に回答することで、ご自身の思考傾向を整理・確認するためのアプリです。

## アプリについて

シンプルな質問に回答していくことで、自分の考え方の特徴や傾向を確認できます。

基本機能は無料でご利用いただけます。
有料版では追加の診断コンテンツをご利用いただけます。

## お問い合わせ

アプリに関する不具合、ご質問、ご意見などがございましたら、下記メールアドレスまでお問い合わせください。

メール：
amanohiroshi@road.ocn.ne.jp

お問い合わせの際は、可能であれば以下の情報をご記載ください。

- ご利用のiPhone機種
- iOSのバージョン
- 発生している問題の内容
- 問題が発生した際の操作手順

## サブスクリプションについて

有料版をご利用の場合、サブスクリプションの管理・解約はApple Accountのサブスクリプション設定から行うことができます。

## プライバシー

Neo思考診断では、ユーザーのプライバシーを尊重し、アプリの提供に必要な範囲で情報を取り扱います。

プライバシーポリシーについては、別途公開するプライバシーポリシーページをご確認ください。
